# 智能求职 Agent

> 一个以“全链路守护求职”为目标构建的个人智能助手。

这个项目不是单一工具，而是一个围绕求职流程组织起来的个人工作区。它将浏览器插件、本地后端服务、macOS 客户端、自动化脚本和可视化看板组合在一起，帮助你更系统地完成求职过程中的每一项工作。

## 项目定位

以求职者为中心，提供从信息整理、条件筛选、主动沟通、进度记录到结果复盘的全链路支持。

```text
信息整理 → 条件筛选 → 主动沟通 → 进度记录 → 数据分析 → 流程复盘
```

## 核心能力

- **浏览器插件**：在求职网站中增强页面交互能力，帮助完成重复性操作。
- **本地后端服务**：统一接收和保存求职流程中产生的数据。
- **macOS 客户端**：管理本地服务，查看运行状态、进度和日志。
- **自动化脚本**：处理规则明确、重复性高的本地任务。
- **可视化看板**：展示求职过程中的关键数据和趋势。

## 快速开始

### 浏览器插件

```bash
pnpm install
pnpm run build
```

构建产物位于：

```text
.output/chrome-mv3
```

在浏览器扩展管理页加载该目录即可。

### 本地后端服务

```bash
cd macos/backend
python3 run.py
```

默认监听：

```text
http://127.0.0.1:5005
```

### macOS 客户端

开发运行：

```bash
cd macos/BossHelperMac
swift run BossHelperMac
```

打包完整应用：

```bash
./macos/scripts/build_app.sh
```

产物：

```text
macos/build/BossHelperMac.app
```
